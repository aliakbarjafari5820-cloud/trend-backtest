# تعریف‌های عددی (یکسان برای همهٔ ارزها و تایم‌ها)

| مفهوم | تعریف دقیق |
|---|---|
| سوئینگ | سقف: High اکیداً بالاتر از ۲ کندل قبل و ≥ ۲ کندل بعد (کف برعکس). بعد از بسته شدن کندل دوم تأیید می‌شه. |
| روند (PA) | دو سقف و دو کف تأییدشدهٔ آخر: HH+HL = صعودی، LH+LL = نزولی، بقیه = خنثی (بدون معامله). |
| شکست (PA) | کلوز بالای آخرین سقف تأییدشده (کندل قبل زیرش بوده)، در روند صعودی. هر سطح فقط یک بار. |
| پولبک (PA) | ظرف حداکثر ۲۰ کندل، Low به سطح + ۰.۱ ATR(14) برسه. کلوز ۰.۵ ATR زیر سطح = شکست باطل. |
| کندل تأیید | کلوز > اپن و کلوز بالای سطح (یا بالای لبهٔ پایین ناحیه در SMC). ورود روی اپن کندل بعد. |
| حد ضرر PA | آخرین کف تأییدشده − ۰.۱ ATR. |
| سوئیپ نقدینگی | Low زیر آخرین کف تأییدشده بره و ظرف حداکثر ۳ کندل کلوز دوباره بالای اون کف بسته بشه. |
| BOS/CHoCH | ظرف حداکثر ۲۰ کندل بعد از سوئیپ، کلوز بالای آخرین سقف تأییدشده. |
| Order Block | آخرین کندل نزولی بین سوئیپ و BOS؛ ناحیه = Low تا High اون کندل. |
| FVG | آخرین گپ سه‌کندلی بین سوئیپ و BOS: Low کندل سوم > High کندل اول. |
| ناحیهٔ ورود | هم‌پوشانی OB و FVG در اولویت، بعد OB، بعد FVG. برگشت به ناحیه + تأیید ظرف ۳۰ کندل بعد از BOS. |
| حد ضرر SMC | پایین‌ترین قیمت سوئیپ − ۰.۱ ATR. کلوز زیر نقطهٔ سوئیپ قبل از ورود = ستاپ باطل. |
| ترکیبی | همان SMC + روند PA در لحظهٔ ورود باید هم‌جهت باشه. |
| حد سود | ۲ برابر ریسک. اگه حد ضرر و حد سود در یک کندل خورده بشن → ضرر حساب می‌شه. گپ از حد ضرر → خروج روی اپن. |
| هزینه‌ها | کارمزد Taker ۰.۰۵٪ + اسلیپیج ۰.۰۲٪ هر طرف، فاندینگ ۰.۰۱٪ هر ۸ ساعت (به ضرر هر دو جهت). |
| ریسک | ۱٪ اکوئیتی هر معامله، سقف اهرم ۲۰x (اگه بیشتر لازم باشه، حجم و ریسک کم می‌شه). حداکثر ۳ معاملهٔ همزمان در کل سبد؛ هر ارز/استراتژی یک معامله در لحظه. |
| بازار | همهٔ قراردادهای دائمی USDT بایننس (شامل حذف‌شده‌ها)، ۲۴ ماه آخر، ۵m؛ تایم ۱۵m و ۱h از روی ۵m ساخته می‌شن. |
