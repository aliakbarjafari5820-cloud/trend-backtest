# استراتژی ۱ — Classic Price Action

> تعریف‌های مشترک (سوئینگ، ATR، قدرت شکست، تلورانس پولبک، کندل تأیید، هزینه‌ها و ریسک) در `00_BACKTEST_PROTOCOL.md`. پیاده‌سازی: `run_pa` در `smc/engine.py`.
> بدون اندیکاتور (RSI، MACD، میانگین متحرک). ATR فقط برای اندازه‌گیری فاصله‌هاست.

## ۱. روند
بر اساس دو سقف و دو کف تأییدشدهٔ آخر:
- **صعودی:** سقف آخر > سقف قبلی **و** کف آخر > کف قبلی (HH + HL) → فقط خرید
- **نزولی:** سقف آخر < سقف قبلی **و** کف آخر < کف قبلی (LH + LL) → فقط فروش
- **خنثی:** بقیهٔ حالت‌ها → معامله نمی‌شه

## ۲. خرید (LONG) — همهٔ شرط‌ها به ترتیب
1. روند صعودی باشه.
2. کلوز حداقل ۰.۵ ATR بالای **آخرین سقف تأییدشده** بسته بشه (شکست).
3. ظرف حداکثر **۲۰ کندل** بعد از شکست، Low به سطح شکسته‌شده + ۰.۲۵ ATR برسه (پولبک).
4. اگه قبل از تأیید، کلوز ۰.۵ ATR زیر سطح بسته بشه → ستاپ باطل.
5. کندل تأیید صعودی: کلوز > اپن و کلوز بالای سطح؛ روند هنوز صعودی باشه.
6. **ورود:** اپن کندل بعد.
7. **حد ضرر:** آخرین کف تأییدشده − ۰.۱ ATR (فاصله باید بین ۰.۱ و ۳ ATR باشه).
8. **حد سود:** ۲R خالص.

## ۳. فروش (SHORT)
دقیقاً قرینهٔ خرید: روند نزولی، کلوز ۰.۵ ATR زیر آخرین کف تأییدشده، پولبک تا سطح − ۰.۲۵ ATR ظرف ۲۰ کندل، کندل تأیید نزولی زیر سطح، حد ضرر = آخرین سقف تأییدشده + ۰.۱ ATR، حد سود ۲R خالص.

## ۴. پارامترها
| پارامتر | مقدار |
|---|---|
| سوئینگ | ۲ چپ / ۲ راست |
| ATR | ۱۴ |
| قدرت شکست | ۰.۵ ATR |
| تلورانس پولبک | ۰.۲۵ ATR |
| حداکثر انتظار برای پولبک + تأیید | ۲۰ کندل |
| ابطال | کلوز ۰.۵ ATR اون‌ور سطح |
| حد ضرر | سوئینگ مخالف ± ۰.۱ ATR، محدودهٔ ۰.۱ تا ۳ ATR |
| حد سود | ۲R خالص |
